# Systems Engineering Glossary: Double-Entry Ledger Core Kernel

### Double-Entry
Accounting discipline requiring every transaction to consist of balanced debits and credits summing exactly to zero.

### Immutable Journal
Append-only cryptographic transaction log preventing retroactive alteration of historical balances.

### Lock Contention
Concurrency bottleneck caused by multiple transactions updating the same hot balance account simultaneously.

### Idempotency Key
Unique client-generated token ensuring duplicate transaction requests execute exactly once.
